# Gatherly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** A polished, usable event planner aligned to all six judging criteria.
**Architecture:** Deterministic calculations with bounded server-side Gemini enrichment. Browser-local workspace and explicit AI provenance.
**Tech Stack:** Next.js, React, TypeScript, Zod, Vitest, Playwright.
**Spec:** docs/superpowers/specs/2026-11-01-gatherly-design.md

## Global Constraints
- One branch named main; repository less than 10 MB; never commit secrets.
- Wedding, birthday and community event support; totals reconcile exactly.
- Clear offline label without credentials; server-only Gemini calls.

## Review Focus
- Bad input and unsupported currency must fail validation.
- Tight budget and near-date events need actionable feasibility warnings.
- Corrupt local storage must recover without breaking the UI.
- Provider failure must show fallback provenance without leaking credentials.
- Edits that regenerate plans must explain progress reset.
